# Подготовка owner-only автоматизации

Автоматизация ещё не подключена: Actions выключены, self-hosted runner отсутствует. `run_policy.py` — проверяемый компонент будущего ограниченного интерфейса запуска, а не готовая система авторизации.

Он принимает только ручной запуск с разрешёнными repository ID, owner ID, workflow path, веткой main и заранее одобренным commit. Проверяется также инициатор повторного запуска и факт старта единственного нужного job после environment gate.

При интеграции данные должны запрашиваться самим сервером через GitHub API, а не приниматься на веру от SSH-клиента. Jobs запрашиваются для текущего run_attempt. Необходимы отдельный replay guard для пары run_id/run_attempt, ограниченный канал без административного SSH-ключа и проверка результатов перед prerelease-публикацией. Одного вызова этой функции недостаточно для безопасного подключения VM.
