# Infinity X 4.1 для POCO X8 Pro Max (`dash`)

Неофициальный порт Android 17. Сборка с GApps и собственными release-ключами установлена на телефон; загрузка и подпись системы проверены. Владелец подтвердил работу камеры, мобильной сети, плавного интерфейса и подсветки задних камер. Полный аппаратный чек-лист ещё не пройден.

После явной настройки встроенных PIF/TrickyStore проходят **Basic, Device и Strong**, Play Маркет сертифицирован. Результат зависит от действующего keybox; текущий сертификат истекает 6 ноября 2026 года. Рабочая конфигурация и порядок её проверки сохранены в [docs/integrity.md](docs/integrity.md), приватные ключи в Git не публикуются.

## Что подготовлено

- Снимок аппаратного дерева `xiaomi-mt6991/device_xiaomi_dash`, `cnb`, commit `574a0737bdc440ba90aa7b28681506ed28a44d9e`.
- Продукт `infinity_dash`, модель `2602BPC18G`, `UNOFFICIAL`; первая сборка была без GApps, установленный release включает GApps.
- 13 зависимостей, закреплённых по commit SHA в `sources/dependencies.json` и `local_manifests/dash.xml`.
- Проверяемый patch `patches/0001-infinity-dash.patch` для применения к оригинальному дереву после `repo sync`.
- Проверки pinned commits, повторного применения patch и защиты от перезаписи чужих изменений.
- Скрипты подготовки и сборки, не содержащие команд прошивки телефона.
- Контроль доступа и целостности сборочного сервера с независимой сверкой на локальном ПК.
- Проверка SHA-256 всех входных файлов и запуск сборки из дерева, закрытого от записи; результаты и логи вынесены отдельно.

## Проверка локального набора

```sh
python3 -m unittest discover -s tests -v
python3 tools/preflight.py
bash scripts/prepare-server.sh /srv/infinity-dash
```

Последняя команда по умолчанию только показывает план и не создаёт каталог исходников. Подготовка на сервере описана в [build/README.md](build/README.md).

## Состояние проверки

Полная сборка `m bacon -j8` завершилась с кодом 0. До и после неё проверен полный снимок исходников. Прошли проверки SELinux/Treble, bootclasspath и VINTF. [Отчёт первой сборки](validation/2026-10-31-build.json) сохранён как история. Затем APK/APEX, OTA/payload и AVB переподписаны собственными ключами; [отчёт установленного release](signing/release-20261031-validation.json) содержит хеши и результаты проверки подписей.

Установленный артефакт: `Project_Infinity-X-4.1-dash-31.10.2026-GAPPS-UNOFFICIAL-RELEASE-v2.zip`, 4 286 098 883 байта, SHA-256 `2d51adbaaa53665c6c61f933872ef85de383d4f94eab56115da8f95ed6256e95`. Он содержит 16 разрешённых разделов, включая проверенный `pvmfw`; `lk`, `preloader`, модем и NV-разделы исключены. Выполнена чистая установка через recovery, система загрузилась со слота B. Приватные release-ключи остаются на ПК владельца.

[Инструкция установки release-v2](docs/install-release-v2.md) описывает проверенный bootstrap и sideload. [Готовность к публикации и maintainership](docs/public-release-readiness.md) отдельно отмечает непроверенные сценарии, вопрос исходников ядра и требования команды Infinity X.

GitHub Actions пока выключены; текущая сборка запущена через SSH. Компоненты будущего ограниченного интерфейса запуска описаны в [ci/README.md](ci/README.md).

Просмотр логов VM: `bash scripts/watch-builds.sh`. Скрипт подключает отдельную tmux-сессию только для чтения. Наличие логов не означает, что сейчас идёт сборка.

Подробности исходников и ограничений: [sources/NOTES.md](sources/NOTES.md). План дальнейших этапов: [docs/superpowers/plans/2026-10-30-infinity-dash.md](docs/superpowers/plans/2026-10-30-infinity-dash.md).

После полной синхронизации зафиксированы конкретные revisions 1245 репозиториев: [build/source-manifest.xml](build/source-manifest.xml). Изменения для `dash` накладываются отдельным patch; manifest не заменяет проверку этих изменений и готовых образов.
